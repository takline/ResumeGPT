Enhance, optimize, and improve ResumeGPT
This commit incorporates a series of enhancements to ResumeGPT, aiming to elevate your codebase to top-tier software engineering standards.

Key improvements include:

- **Error Handling:** I implemented more specific and robust error handling throughout the application, particularly in service layers and file operations, with improved logging.
- **Refactoring & Readability:** I refactored core components like `ResumeImprover` for better clarity, modularity, and maintainability. This involved breaking down large methods and improving naming conventions.
- **Modularity:** I separated PDF generation logic into a dedicated `PDFGenerator` class.
- **Efficiency:** I introduced API response caching (LLM and HTML downloads) and optimized data processing logic. I refactored `BackgroundRunner` to use `ThreadPoolExecutor` for better concurrency management.
- **Test Coverage:** I significantly increased unit test coverage for `ResumeImprover`, the new `PDFGenerator`, `BackgroundRunner`, and HTML caching mechanisms.
- **Security:** I reviewed API key handling, confirmed secure practices (prioritizing environment variables), and updated documentation to guide you on secure configuration.
- **Dependencies:** I reviewed and updated dependencies in `pyproject.toml`, removing redundant packages (`ruamel.yaml`) and updating others (e.g., `PyYAML`, `python-dateutil`).
- **Documentation:** I comprehensively improved code documentation by adding/updating docstrings (module, class, method/function levels) and inline comments across all major modules.
